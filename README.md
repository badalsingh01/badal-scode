# badal-scode

**Daily DSA practice to become a stronger problem solver and competitive programmer.**

This repository tracks my journey through data structures and algorithms in C++. My goal is to build strong fundamentals, recognize problem-solving patterns, and improve my speed and accuracy in programming contests.

## Goals

- Solve problems consistently and understand why each solution works.
- Learn to move from a brute-force approach to a more efficient solution.
- Analyze time and space complexity.
- Handle edge cases and write clear, reliable C++ code.
- Improve under contest time limits through practice and review.

## Daily practice routine

1. **Understand the problem:** identify the inputs, constraints, and expected output.
2. **Try independently:** work through examples and start with a simple approach.
3. **Improve the approach:** look for a useful data structure or algorithmic pattern.
4. **Implement and test:** check sample cases, boundary cases, and tricky inputs.
5. **Review:** note the complexity, mistakes, and key idea.
6. **Revisit:** solve difficult problems again later to check my understanding.

The aim is steady progress and deeper understanding, with problem difficulty adjusted to what I am learning.

## Solution notes

For each completed problem, I aim to record:

- **Problem:** the title and a link to the original statement, when available.
- **Approach:** the key observation and why the algorithm works.
- **Complexity:** time and auxiliary space, with the variables defined.
- **Checks:** important edge cases and tests.
- **Takeaway:** what I learned or what I would improve next time.

These notes can live alongside the solution as comments or in the day's folder.

## Contest practice

- Practice timed problem sets and take part in contests regularly.
- Read constraints carefully and prioritize problems I can solve confidently.
- After each contest, upsolve problems I could not finish.
- Review wrong answers, time-limit errors, and implementation mistakes.
- Revisit recurring patterns and track where time was lost.

## What progress means to me

Progress means solving more problems independently, explaining my reasoning clearly, making fewer repeated mistakes, and staying composed under time pressure.
